# Changelog

Все заметные изменения этого проекта документируются здесь.

Формат основан на [Keep a Changelog 1.1.0](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

Разделы: `Added` (добавлено), `Changed` (изменено), `Deprecated` (устарело),
`Removed` (удалено), `Fixed` (исправлено), `Security` (безопасность).

## [0.2.0] (не выпущено)

Telegram-бот поверх готового ядра. Тег появится после проверки на живом
бот-аккаунте, до этого версия считается в разработке.

### Added

- Бот на aiogram 3: `/start`, `/help`, `/about` и свободный текст с
  ингредиентами через запятую.
- Три страницы подбора: «только своё», «докупить 1», «докупить 2». Страница
  означает ровно N недостающих ингредиентов, поэтому каждое нажатие даёт
  другой список.
- Пустые страницы не показываются кнопками. Если пусто на строгой странице,
  бот сам переходит к следующей и объясняет, почему показывает не то, что
  просили.
- Листание внутри страницы: пять карточек на лист, стрелки «назад» и
  «вперёд», позиция в шапке («Показаны 6-10 из 33»), сквозная нумерация.
  Стрелка есть только там, где действительно есть карточки.
- Русский текст в карточке: английское название с переводом в скобках и
  полный состав новой строкой, ниже «докупить: ...». Нет перевода - нет
  скобок: выдуманное название хуже английского.
- `data/translations.yaml` с подписями для вывода, отдельно от синонимов
  поиска. Ингредиенты переведены полностью (300 из 300 названий, 100% строк),
  коктейли - 189 из 441.
- Покрытие перевода в `cocktail report`: текст и JSON. Настройка через
  `Config.translations_path` и переменную `COCKTAIL_TRANSLATIONS`.
- Команда `cocktail bot` с флагом `--token`. Без токена - подсказка про
  @BotFather, а не трейсбек.
- Тесты: разбор ввода, страницы, листание, переводы, кэш запросов, сборка
  диспетчера. Без сети и без токена.
- CI ставит extras `bot` и проверяет CLI на реальном снапшоте.
- Количества в составе: унции, ложки и чашки пересчитаны в миллилитры,
  штучные единицы склоняются по-русски («1 долька», «2 кубика», «5 дэшей»).
  Если в каталоге количество не указано, оно не рисуется.
- В карточке появились бокал, тип напитка и метки: «классика IBA»,
  «современная классика IBA», «безалкогольный». Ссылка «Смотреть видео»
  добавляется, если ролик есть в каталоге (24 напитка).
- Рецепт по кнопке «Как готовить»: текст открывается в том же сообщении,
  повторное нажатие убирает. Кнопка есть только у переведённых рецептов,
  английский текст не показываем. Переведено 38 из 441.
- `data/translations.yaml` получил секцию `instructions`, `Translator` -
  методы `instruction` и `has_instruction`, отчёт - строку покрытия рецептов.
- Кнопки страниц называются с заглавной: «Только своё», «Докупить 1»,
  «Докупить 2», «Докупить 3». Страниц докупки стало три вместо двух.
- На стрелках написан номер, к которому они ведут: «Назад к 5» и
  «Вперёд к 7» вместо безликих «назад» и «вперёд».
- Фотография коктейля в карточке: `strDrinkThumb` из каталога, есть у всех 441
  напитка. Бот отправляет ссылку, картинку скачивает сервер Telegram.
- Карточки показываются по одной, стрелки листают по одной. Позиция в шапке:
  «Коктейль 6 из 33». Раньше на листе было пять карточек без фотографий.
- В составе рядом с русским названием ингредиента показывается оригинал
  в скобках: «водка (Vodka), сок лимона (Lemon juice)». Если перевода нет,
  скобок нет. Строка «Докупить» остаётся короткой, по-русски.
- Жирное выделение в карточке: название коктейля, «Состав» и «Докупить».
  Сообщения уходят с `parse_mode=HTML`, динамические строки экранируются:
  название вроде «AT&T» уходит как `AT&amp;T`.
- Подпись «Стрелки листают список, кнопки внизу меняют, сколько нужно
  докупить» убрана: интерфейс понятен без неё.

### Changed

- Версия 0.2.0. Дорожная карта: этап 6 (бот) закрыт, REST остаётся
  отложенным до появления потребителя вне процесса.

### Fixed

- «Состав» и «Докупить» выглядели сдвинутыми друг относительно друга:
  строки начинались с трёх пробелов, а Telegram по-разному обращается
  с ведущими пробелами в подписях к фото. Отступ убран, все строки
  карточки идут от левого края.
- При листании карточек менялось только описание, а фотография оставалась
  от предыдущего коктейля: `edit_caption` правит подпись, но не картинку.
  Теперь для сообщений с фото используется `edit_media` с новым снимком.
- Роутер был модульным синглтоном, а aiogram запрещает подключать его дважды:
  второй `create_dispatcher` падал с `Router is already attached`.
- Тесты читали локальный `.env`, и с настоящим токеном тест «бот без токена»
  уходил в Telegram.
- CLI падал с `UnicodeEncodeError` на консолях, которые не умеют печатать
  кириллицу (cp1252 на Windows-раннере): теперь вывод деградирует до `?`,
  а код возврата остаётся осмысленным.
- `UnicodeEncodeError` наследуется от `ValueError` и раньше попадал в общий
  обработчик ошибок, который падал повторно при печати сообщения.
- CI-шаг `Smoke test CLI` прятал провал за `|| echo`. Теперь он проверяет
  живучесть точек входа, а содержимое ответа - `tests/test_integration.py`.

## [0.1.0] - 2026-11-01

Первый рабочий каркас: каталог скачивается, разбирается и ищется по
ингредиентам. Бота, REST и MCP пока нет - они следующие этапы.

### Added

- Каркас проекта: `pyproject.toml` (hatchling, версия из `cocktail.__version__`),
  строгие настройки ruff и mypy, pytest с `--strict-config`, CI на GitHub Actions
  (Ubuntu и Windows), `Makefile`.
- Модели предметной области: `Cocktail`, `IngredientMeasure` - неизменяемые,
  с сериализацией в JSON для снапшота.
- Загрузка каталога TheCocktailDB: клиент на `httpx`, обход по алфавиту
  (`a-z`, `0-9`), дедупликация по `idDrink`, атомарная запись снапшота
  через `.tmp` + rename.
- Разбор рецептов `parse.parse_measure`: числа, дроби (`1 1/2`, `½`, `1,5`),
  единицы (oz, cl, ml, dash, tsp, tbsp, …), «juice of 1/2», пометки
  «to taste»/«for garnish», сохранение исходной строки в `raw`.
- Нормализация названий: словарь алиасов из `data/aliases.yaml`
  (русские и английские синонимы) плюс токенизация со стоп-словами.
- Поиск `search.find`: сопоставление по канонам, множествам слов и вложенности
  с защитой от коротких слов; ранжирование по числу недостающих ингредиентов,
  затем по покрытию, затем по алфавиту - результат детерминирован.
- CLI на argparse: `fetch`, `find`, `report`, `version`, флаги `--json`,
  `--max-missing`, `--limit`, `--snapshot`, `-v`; коды возврата 0/1/130.
- Отчёт `report.build_report`: доля строк с количеством и единицей, частотные
  словари ингредиентов и нераспознанных строк - измеримая база для этапа 2.
- Словарь алиасов `data/aliases.yaml` с черновым набором (~90 канонических
  названий, включая русские формы); на реальном каталоге распознаётся 86,7%
  строк с количеством (441 напиток, 1730 строк ингредиентов).
- Тесты (pytest, без сети): разбор рецептов, нормализация, поиск, снапшот,
  клиент API на `httpx.MockTransport`, CLI, конфигурация, отчёт.
- Документация: README с быстрым стартом, структурой, правилами данных
  и дорожной картой; этот CHANGELOG.

### Notes

- Формат снапшота: `schema: 1`, сырые объекты API в `items` - разбор
  выполняется при загрузке, поэтому парсер можно менять без повторных
  скачиваний.
- Заглушка `cocktail.bot` фиксирует место для Telegram-бота; зависимость
  `aiogram` объявлена отдельным extras `[bot]` и на этом этапе не ставится.
